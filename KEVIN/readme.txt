4 Mappar:
1. Main ESP:
	Innehåller de två nyaste kända versionerna av programmet som kördes på explora ballongen.
	Kan till och med vara så att bt_multiple_devices2.ino är den officiella filen.

2. ESP32 Camera Module
	Filer relevanta för kameramodulen som flög ombord Expolora (esp32cam)
	- MarcV1english.ino : En "mall" gjord av en av de franska lärarna från lyce de lespace
	- mainAndCamComs.ino : Kan vara vår flygvärdiga projektfil.

3. tests
	ino-filer som vi skapat för att testa olika idéer, system eller sensorer.
	Inkluderade endast några få.
	- GPS testet fick vi aldrig att fungera (och var tvugna att ta bort från ballongen),
	  Vet inte om det berodde på hård- eller mjukvara.
	- ESP32 Wifi Server : Server som kördes från en ESP32, anvädnes som testmiljö för att trådlöst
	  motta mätvärden från sensorer (i denna version temperatur & luftfuktighet)
	- Log test.txt : Exempelfil för att illustrera hur vi sparade data som samlades av mikrodatorn.
